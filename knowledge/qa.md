# 台本制作Q&A（AKへ回した質問の回答ログ）

次に同じ種類の質問が来た時は、まずここを検索してから回す。

形式：

```
## YYYY-MM-DD 質問の要約
**案件**: 台本id または案件名（分かれば）
**質問**: 実際に聞いた内容
**AKの回答**: 回答をそのまま
**適用範囲**: この案件限定 / このチャンネル共通 / 全案件共通
```
