# 密着ドキュメンタリーのタイトルを作る（壁打ち＋事実照合）

2026-10-09 石野華鳳様（書道）案件で確立。サムネの方向が決まってから作る。

## 原則

- タイトルは**未解決の問い（質問13のQ10）**を担当する
- 企画軸をそのまま問いにしない（「なぜ教える人になったのか」では刺さらない）。**最初に決めた身体感覚（苦しみ）**を載せる
- **冒頭は専門用語で始めない**。「書道をやめて」から始めると書道に興味がある人しか見ない。誰にでも刺さる落差から入る
- 流れは「落差のある過去 → 今の姿 → なぜ？」
- 1案ずつ違う軸で3案出し、違いを1行ずつ添えて、推しを1つ言う

## 進め方（1問ずつ）

1. 載せたい流れをAKに言ってもらう（例：学校を辞めてギャル・不良だった少女 → 350人に書道を教えている → なぜ）
2. 事実に合わせて言い直した3案を出す
   - A：流れそのまま
   - B：落差を一段強く＋「理由」で問いを立てる
   - C：一番短い（スマホで全文が見える）
3. AKが選んだ案を、**事実照合表**で確認する

## 事実照合表（必ず出す）

| タイトルの言葉 | 出どころ | 判定 |
|---|---|---|
| 例：進学校 | 本人「高校は進学校行ってるんです」／履歴書 | OK |
| 例：不良 | 履歴書は「ヤンキー」 | 言い換え |
| 例：350人 | 同席者の発言 | 要確認 |

- 出どころは「本人の発言／同席者の発言／本人公開の資料／Claudeの言い換え」を分ける
- 数字が公開情報と食い違う時は、両方を示して先方確認にする
- 本人が言っていないラベルは使わない（例：「不登校」ではなく「高校を2週間で中退」）
- 言い換えを使うかはAKが決める（例：AKの判断で「不良ギャル」）。本人の言葉に寄せた候補も添える
- ご家族の事情など、センシティブな言葉は先方の許す表現に揃える

## 最後に

- サムネの上の行・小さい行との重なりを確認する
- ものがたりっちの `meta.titles` に入れる（AKがアプリで直していたら上書きしない）
