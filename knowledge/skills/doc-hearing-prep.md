# 密着ドキュメンタリーのヒアリング前リサーチと質問リスト

2026-10-06 石野華鳳様（書道）案件で確立。井下さん、AstroX、宙畑の案件でも同じ流れを繰り返していたものをまとめた。

## 進め方の原則

- 返答は短く、一瞬で要点が分かる形にする
- 公開情報で確かめた事実と、Claudeの仮説（★）を必ず分ける
- 出どころ（本人の発言／本人公開の資料／記事／非公式ブログ）を添える。資料ごとに数字が違えば、違いをそのまま示す
- 1回で完成させない。AKの指摘を受けて、段ごとに直す

## 順番

1. **人物リサーチ**
   - 公式サイト、本人の発信（YouTube・SNS）、取材記事、プレスリリース、クラファンページを当たる。クラファンや本人の長文には、本人の言葉で書かれた経歴が多い
   - 事業の柱、会社の形（法人が複数あるか、誰が何を担当するか）、数字、経歴を短くまとめる
   - 関係する取引先とのつながり（例：FANTSの導入事例インタビュー）も拾う
2. **山と谷（仮説）**
   - 時期・出来事・山か谷か、を表にする。公開情報にない谷は★で仮説と明記する
   - 「物語の芯」を1行で置く（例：書道を選んだ人ではなく、書道しか残らなかった人が、書道を残す側に回った）
3. **本人の資料が来たら直す**
   - 幸福度グラフや「わたしの履歴書」が届いたら、それを正解にして山と谷を直す。仮説が外れた所ははっきり訂正する
   - 外から見た絶頂と本人の底が同じ年になっていないかを見る（例：日展入選・Google選出の年に、本人は「忙しすぎて体調不良」で最深の谷）
4. **質問リスト（大きい領域から）**
   - まず**ビジネスの全体像**と**ストーリーの全体像**を聞く。ここで7〜8割わかる
   - 残り2〜3割で枝葉を掘り、本人が繰り返す言葉・言いよどむ所・急に早口になる所（金脈）を探す
   - 谷の深掘りから入らない。全体を聞いている間は「なぜ」を我慢してメモだけにする
   - AKが出した進行の型があればそれに乗せる。例：現在の活動（クリエイター側・ビジネス側）→ 活動のきっかけ → 原点 → なぜその道か → 一番大変だった時期 → 取引先サービスとの出会いと変化 → 今大変なこと → 今後の目標
5. **動画の目的に寄せる**
   - 目的（集客、取引先サービスへのつなぎ等）を確かめ、視聴者が2層なら両方に効く軸を1つ置く（例：「上手くなる」より「続く」）
   - 取引先サービスは主役にせず、その「場」として映る形にする
   - 「一番変わったお客さん（生徒さん）は誰か」を必ず聞く。撮影で登場してもらえる具体的な1人が、集客にもサービスの証拠にもなる
6. **クライマックス候補**
   - 現在の活動の中身（学び・交流・リアルのイベントなど）を公開情報から洗う
   - 候補を表にする（リアルの集まり／お客さんの挑戦の結果／本人の作品／お客さんが教える側に立つ場面 など）
   - 当日聞く：撮影期間内に人が集まる予定、結果が出る予定、「いま準備していて一番緊張しているもの」

## センシティブな扱い

- 家族の事情、いじめ、体調不良などは、本人が公開している範囲に留め、こちらから掘らない
- 体調は病名ではなく「当時の一日」を聞く
- ご存命か分からない人（祖父母など）は、どちらでも答えられる聞き方にする（例：「おじいさまの教室は、今どうなっていますか」）
- 本人の名前の読み方は公式表記で確かめて添える

## 出力

- 人物の要約（短く）
- 山と谷の表（★付き）
- 質問リスト（全体像 → 枝葉 → 金脈の目印）
- クライマックス候補と当日聞くこと
