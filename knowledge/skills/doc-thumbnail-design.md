# 密着ドキュメンタリーのサムネを作る（壁打ち）

2026-10-09 石野華鳳様（書道）案件で確立。構成（苦しみ・敵・型・企画軸）が決まってから作る。

## 役割分担

- **サムネ＝質問13のQ9**：見た瞬間に身体が反応するもの。絵で見せる
- **タイトル＝Q10**：最後まで見たくなる未解決の問い。言葉で置く
- サムネとタイトルで同じ言葉を繰り返さない（最後に重なりを確認する）

## 型（参考：着物スタイリスト密着のサムネを分解）

| 位置 | 役割 | 石野さん案件 |
|---|---|---|
| 上 | 経歴の落差 | 高校2週間で中退・元ギャル |
| 写真 | 落差の絵、または職人としての熱狂の1枚 | 教える姿（予備：書く姿） |
| 中央 | 本人の強い言葉 | 「派手なだけの字は、100均と同じ」 |
| 小さく | 権威の裏付け（3行まで） | 生徒350人／日本最大級の美術展で入選／Google「日本のトップクリエイター100」選出 |
| 下 | 職業＋密着 | 教育書道家 密着 |

## 進め方（1問ずつ）

1. **最初に起こしたい反応**：「え？」（落差）か「きれい、何この人」（引力）か
2. **写真の主役**：落差の2枚並べ（過去の写真＋今）か、熱狂の1枚か
   - 熱狂の1枚は、その人の熱が一番出る行為で撮る（作品を作らない人なら、書くより教える）
   - 第一候補と予備を決め、撮影当日は両方押さえる
3. **中央の言葉**
   - 本人の言葉から選ぶ。抽象的な比喩はそのまま使わず、何がそうなのかを具体にする（「100均の字」→「派手なだけの字は、100均と同じ」）
   - 上の行と組み合わせて皮肉や説得力が乗るか見る（派手だった元ギャルが「派手なだけはダメ」と言う）
   - 特定のジャンルや人を下げる読み方にならないか確認する
   - サムネの言葉が本編で回収されるか確認する
4. **上の行（経歴の落差）**：一番短く、一瞬で「え？」が起きるもの
5. **小さい行（権威）**
   - 一度考えないと分からない情報は外す（「書道の先生100人が生徒」→「生徒350人」）
   - 業界用語は初心者向けに言い換える（「日展入選」→「日本最大級の美術展で入選」）
   - 「最大」と言い切らず「最大級」にする
   - 数字・賞はすべて先方に使用確認
6. **下の行**：職業名＋密着
7. **タイトルとの重なりを確認**して、重なる行は替えるか残すかAKに判断してもらう

## 出力

決まった5要素を表で出し、ものがたりっちの `meta.thumbs` に入れる（AKがアプリで直していたら上書きしない）。要確認の数字・使用可否を下に添える。
