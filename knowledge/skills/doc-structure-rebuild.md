# 密着ドキュメンタリーの構成を組み直す（壁打ち）

2026-10-09 石野華鳳様（書道）案件で確立。ものがたりっちに台本が入った後、「すごい人にしか見えない」「ターゲットの身体感覚まで届いていない」と感じた時に、構成の土台から組み直す。

## 進め方の原則

- **1問ずつ聞く。** Claudeが仮説を1つ置き、AKが直す。案を一度に出しすぎない
- 答えは短く。決まった項目は、その都度1〜2行で固定して見せる
- 質問13（GitHub MONOGATARI `knowledge/SCRIPT_PRODUCTION_MANUAL_V1.md`）の番号に沿う。事実系はClaudeが埋め、感情系（Q2/5/9/11）はAKに聞く
- 根拠は必ず台本（文字起こし由来）と本人公開の資料。本人の言葉か、同席者の言葉か、資料か、Claudeの言い換えかを区別して示す

## 順番

1. **苦しみ（Q1）**：ターゲットの苦しみ
   - 限定しすぎない（「評価はされているのに中身がない」は狭すぎた）
   - 抽象にしすぎない（「自分では選べないこと」は刺さらない）。具体的な場面で持つ
   - 本人の事実と合うか確かめる。才能があった人に「向いてないと言われた」は合わない
2. **奥の感覚（Q2）**：怒り／諦め／空っぽ など、AKに選んでもらう。視聴者がそれをどう「動かない理由」にしているかまで聞く
3. **日常と喪失**：日常の核は「手段（書道）」ではなく「その人にとっての喜び（教えて喜ばれる）」で取る
4. **敵**：視聴者が最初に敵視するもの。具体的な場面を2〜3個並べる（例：家庭の事情での転校／偏差値で順位がつく進学校）。センシティブな事情は先方の許す表現に統一する（例：「家庭の事情で両親と離れる」）
5. **型を選ぶ**：ターゲットに合う物語の型を決める
   - 女性・スピリチュアル寄りの層 → 戦って勝つ話より、**シンデレラ型（行いがあったから運命に導かれた）**
   - 型の各段（不遇→行い→魔法→12時の鐘→ガラスの靴）に、本人の事実を1つずつ当てる
   - 「行い」は本人が自分で始めたと書かない。事実どおり（例：祖父に連れられ、行きたくはなかったが通い続けた）
   - 「運命」は本人に言わせない。タイトル・構成側の言葉として使う
6. **企画軸を1行で決める**：苦しみ（入口）とゴール（出口）が1本に入る言い方
7. **過去パートの場所割り**：1か所に7分以上の座り話を固めない
   - 重い話・余白（沈黙の問い）は落ち着いた席で
   - 同席者のセリフが多い話・明るく戻したい話は車内などで
   - 「靴（才能が合う瞬間）」はクライマックスの直前に置く
8. **締め（クライマックス②）**：過去の自分に戻る問いにしない（「今の本人は当時と違う」）。**今の本人の信念＝何を変えたくてやっているのか**を聞く
   - 信念の候補を本人の言葉から2つに絞ってAKに選んでもらう
   - 選んだ信念の素材は、それまでのシーンから外して締めに寄せる（同じ話を2回出さない）
   - 答えは台本に書かず、素材として添える
9. **ものがたりっちへ反映**：`get_script` → 変更 → `update_script`（baseUpdatedAt付き）。メモ（芯・型・苦しみ・敵・靴）、企画軸、視聴者も更新する。競合したら取り直し、AKがアプリで直した所は上書きしない

## よく出た修正

- 「なぜ教える人になったのか」だけでは刺さらない → 身体感覚（苦しみ）を軸に戻す
- 敵を抽象化しすぎ → 具体的な場面で持つ
- 締めを「あの頃の自分へ」にしがち → 今の信念にする
