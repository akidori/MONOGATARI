# 企画一覧のUI改善

参考: https://github.com/lnkiai/m3e-canvas （確認時 HEAD: 920b29882770f0756a0c9ea45ed7df4cc4a8e7fa）

Material 3 Expressiveの操作の強弱・面によるグルーピング・フォーカス表示を参考に、ものがたりっちの既存配色と操作順を維持して実装。参考側のソースコードの転載や依存追加は行っていない。

- 台本へ進む主操作を塗りのあるボタンにし、企画メモと参考動画の補助操作を区別。
- サムネ文言を入力欄として見分けやすくし、撮影・初稿・投稿を一まとまりの予定として表示。
- 丸みと余白を統一し、タッチ操作のターゲットを拡大。
- キーボードフォーカスを強調し、動きを減らす端末設定に対応。
- ダイアログの閉じるボタンをスクロール中も上部に保持。

対象はアプリ内の企画一覧。共有ページ・設定・Worker・DBには変更なし。
既存の合成データを使うブラウザテストで320/390/640/641/1024/1440pxの表示、編集、保存、再読込、既存フィールド保持、台本への移動を確認。顧客データの書換えや実APIへの書込みは行わない。
