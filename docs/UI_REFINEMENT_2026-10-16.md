# 企画一覧のUI改善

参考: https://github.com/lnkiai/m3e-canvas （確認時 HEAD: 920b29882770f0756a0c9ea45ed7df4cc4a8e7fa）

Material 3 Expressiveの操作の強弱・面によるグルーピング・フォーカス表示を参考に、ものがたりっちの既存配色と操作順を維持して実装。参考側のソースコードの転載や依存追加は行っていない。

- 台本へ進む主操作を塗りのあるボタンにし、企画メモと参考動画の補助操作を区別。
- サムネ文言を入力欄として見分けやすくし、撮影・初稿・投稿を一まとまりの予定として表示。
- 丸みと余白を統一し、タッチ操作のターゲットを拡大。
- キーボードフォーカスを強調し、動きを減らす端末設定に対応。
- ダイアログの閉じるボタンをスクロール中も上部に保持。

対象はアプリ内の企画一覧。共有ページ・設定・Worker・DBには変更なし。
既存の合成データを使うブラウザテストで320/390/640/641/1024/1440pxの表示、編集、保存、再読込、既存フィールド保持、台本への移動を確認。顧客データの書換えや実APIへの書込みは行わない。

## 作業画面への展開

概要、構成台本（トーク・ドキュメンタリー）、取材メモ、香盤表、素材管理、動画確認、納品、共有・連携設定にも共通の入力欄・補助操作・カード見出し・フォーカス表示を適用。ホーム本文と公開共有ページのレイアウトは対象外。

- スマホでは入力文字を16pxにし、狭い画面の制作情報フォームを1列にする。
- 選択中の作業タブを直接URLや再読込でも見える位置に寄せる。
- 動画・素材のファイル選択にキーボードフォーカスを提供。未共有の素材アップロードは無効のまま保持。
- 設定画面のTailwindはビルド済みローカルCSSを利用。CSS変更もキャッシュ更新の版番号に含める。
- `test:workspace-ui` は320/390/1440pxで各画面の横はみ出し、現在地、台本編集の保持、素材あり・動画あり画面と設定を検証。合成データを使い、API・送信通信は遮断。実動画再生・実アップロード・AI接続テストは含まない。
- `verify:prod` にapp.css/tailwind.css/settings.htmlの一致確認を追加。

## ホームの整理

独立した「今日やること」チェックリストをホームから外した。期限・担当・Studio OS の「今日の仕事」は「担当と納期」画面で確認できる。ガイドの旧 `#start=today` リンクは維持し、内容と「やってみる」の移動先を「担当と納期」に変更。保存済みの手動TODOは削除せず、`today-todo-v1` に残す（ホームからの編集は現在不可）。
