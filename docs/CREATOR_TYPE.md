# クリエイタータイプ診断

2026-09-29 AK「編集の時間とかを把握するために、クリエイタータイプ診断をものがたりっちの中に搭載するのはどう？」
「これで整理されたら Googleカレンダーとかに自動でスケジュール提案」。まず AK 自身で試す。

## いまできること（第1段階）

- ホームの左メニュー（スマホは上のボタン）「タイプ診断」から開く
- 回答は `window.storage` の `creator-profile-v1` に保存（ログイン中はアカウント別のクラウド保存＝Worker の既存 `/api/kv`。Worker の再デプロイは不要）
- 計算は `src/creator-type.js`、テストは `tools/test-creator-type.mjs`

### 聞くこと

| 区分 | 内容 |
|---|---|
| あなたについて | 動画編集は本業／副業／学生・その他、得意分野（複数） |
| 作業できる時間 | 平日・土日の1日あたりの時間、作業しない曜日、集中が続く長さ（30分〜3時間以上） |
| 工程ごと | 構成・あら編集・テロップ入力・演出・最終調整の好き度（★1〜5）と、10分の動画でかかる時間 |
| 作業のクセ（12問） | 5段階。4つの軸に3問ずつ |

生年月日・性別は聞かない（作業時間の見積もりに使い道が無く、個人情報を預かるだけになるため。AK了承済み）。

### 4つの軸とタイプ

MBTI の設問は流用せず、作業の仕方に直結する軸で自前に作った（時間帯は朝型・夜型の研究〔MEQ など〕の考え方を参考にした）。

| 軸 | 両端 |
|---|---|
| 時間帯 | 朝 ⇔ 夜 |
| 集中の取り方 | まとめて ⇔ 細切れ |
| 着手 | 前倒し ⇔ 締切 |
| 仕上げ | こだわり ⇔ スピード |

タイプ名は「集中の取り方 × 着手」の4つ。時間帯と仕上げはタグで付ける。

| | 前倒し | 締切 |
|---|---|---|
| まとめて | 先行ダイブ型 | 一撃集中型 |
| 細切れ | コツコツ積み上げ型 | すき間スプリント型 |

### 出すもの

- タイプ（強み・気をつけたいこと・4軸の位置）
- 制作の流れ：工程ごとの時間（回答の時間に余裕を上乗せ：締切型 +15%、こだわり +20%）、作業する時間帯（朝型→午前・夜型→夜・中間→午後）、1回の作業の長さ、工程ごとの助言（頭を使う工程は冴える時間帯に／苦手な工程は好きな工程の直後に置くか分担を相談 など）
- 作業予定：動画の長さ・作業開始・納期（案件から選ぶと納期が入る）から、使える時間に工程を順番に割り振る。自分締切は納期の前日（締切型は2日前）。足りない時は不足時間を出す
- `.ics` ダウンロード：Googleカレンダーの「インポート」で取り込める

## プロフィール共有・ポートフォリオ（第1.5段階）

2026-09-29 AK「この診断ツールの中にポートフォリオとかも回答してもらって、このURLと募集文を渡したらこの人のことがわかるようにしたい」

- 回答の「5. プロフィール・ポートフォリオ（共有用・任意）」：表示名・経験・使えるソフト・自己紹介・SNS/連絡先URL・ポートフォリオ（URL・作品名・担当した工程・ひとこと、10件まで）
- 結果画面「プロフィールを共有する」→「共有URLをコピー」。URLは `https://monogataritch.pages.dev/#creator=…`
  - 回答を圧縮して `#` 以降に入れている（`#` 以降はサーバーに送られない＝ものがたりっち側に保存しない。Worker の再デプロイ不要）
  - 回答を変えたら、URLもコピーし直す（古いURLは古い回答のまま）
  - http(s) 以外のURL（javascript: など）は載せない
- URLを開くと、ログインなしの読み取り専用ページ（`CreatorPublicPage`）：タイプ・作業時間・月の目安本数・工程ごとの好き度と時間・得意分野・ソフト・ポートフォリオ
- 「募集文と照らし合わせる」：募集文を貼ると、得意分野・ソフト・尺（◯分）・本数（月◯本）・急ぎ・品質重視・平日日中 をキーワードと数字で照らし合わせる。「プロフィール＋募集文をClaudeにコピー」で、AIに判断させる文を作る
- 今のURLは画面で開く形なので、AIにURLだけ渡しても中身は読めない。AIには「Claudeにコピー」の文を渡す。Worker を再デプロイしたら、短いURL（サーバー保存・AIがそのまま読める形）に切り替える

## この先（案）

1. 案件の工程（Studio OS）と診断の5工程を対応づけ、「あなたの担当」「担当と納期」に工程ごとの作業予定を出す

3. 実績で補正：工程の完了時刻から実際にかかった時間を記録し、申告の時間を自動で直す
4. AK 向け：メンバーの得意・苦手を担当の割り振りの参考に出す
