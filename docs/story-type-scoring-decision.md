- `tools/SCRIPT_GEN_PROMPT.md`「①前提条件」にキャンベル／シンデレラ／ストーリースパインがあるが、用途の説明だけで採点基準ではない。

- UI用の`STORY_FRAMEWORKS`は`spine / pixar / kishotenketsu / threeAct`（pixarは5段表示）。`mg:spineFw`は端末共通設定、`rows[].spine[fw]`は段階の手動割当。いずれも案件ごとの生成型ではない。生成型を確実に保存・送信する経路は確認できなかった。
- 従来のWorkerは固定8項目で採点し、結果の`mg:scriptReview:<project.id>`には型・rubric版がなかった。
- checkoutにAGENTS.md / `.agents/skills`はなく、`CLAUDE.md`の機能保全規約を確認。open PR35/36とStudioOSは変更していない。

## 実装範囲と動作

| 入力・状態 | 動作 |
| --- | --- |
| 採点パネルを開く／未設定／旧リクエスト | 従来Pixar7段＋スパインの8項目。勝手に代替型へ移行しない |
| 今回の採点でCampbell／Cinderella／Story Spineを明示 | 6共通項目を送信。骨組み・2段クライマックスはサーバーでnullを強制し平均除外、該当キーの指摘も除外 |
| 未知文字列・オブジェクト・配列等の型 | 400で拒否。AI呼出し・利用回数更新をしない。型を無理に推測しない |
| 基準版の不一致 | 409で拒否 |
| 旧Worker／対応確認の読込失敗 | 認証付き確認GETが成功するまでPOSTしない。既存結果を保持して再試行を案内 |
| 応答の型・版が不一致 | 結果を表示・保存せずエラー。以前の結果を保持 |
| 旧結果／現在の選択と異なる結果 | 実際の結果の型、または「従来基準（型の記録なし）」を明示 |
| 採点中に閉じる／案件・アカウント切替 | パネルを破棄し、遅れて届く旧応答を表示・保存しない |

選択は採点パネル内の一時状態のみ。開き直すと従来基準に戻ることを画面に明記した。案件・生成型・端末共通の背骨設定の自動保存やデータ移行は追加していない。採点結果は既存のlocalStorageキーに実際の型と版を添えて保存する。

共通の因果関係・反転の主体は既存マニュアルに基づいて質問と答えのつながりの項目で確認する。代替型のpromptでは正本を変更せず、採点用参照から手順3だけを除外する。他項目や総評へPixar要件を転嫁しないよう指示する。NG優先・AK例外・質問文脈・機械チェック・判断材料なしnullは維持。結果正規化でも対象キー制限、最大15件、同一場面/項目の重複除外を行う。
