## 現在の重要な制約

- GoogleログインはGoogle Drive保存ではない。
- 案件JSONは、ログイン時もCloudflare KVへ保存される。
- Cloudflare Stream個人接続はコード実装済みだが、OAuthクライアント設定と公開化が必要。
- 本体AIは利用者が設定したAPIキーをまだ利用しない。
- 一般公開前に、AI回数・ファイル容量・ゲストアップロードの利用者別上限が必要。
- `settings.html` のAIキー設定と本体AI機能は現在分離している。
